# Student Grade Tracker

## About the Project

Student Grade Tracker is a Java-based console application developed as part of the CodeAlpha Java Programming Internship.

The application helps users manage student names and marks and generates a summary report.

## Features

* Enter student names and marks.
* Store student data using arrays.
* Calculate average marks.
* Find the highest marks.
* Find the lowest marks.
* Display a report of all students.
* Validate marks between 0 and 100.

## Technologies Used

* Java
* Java Scanner
* Arrays
* Loops and Conditional Statements

## Requirements

* Java Development Kit (JDK)
* Visual Studio Code or any Java-supported IDE

## How to Run

### Step 1: Compile the program

Open the terminal in the project folder and run:

```bash
javac StudentGradeTracker.java
```

### Step 2: Execute the program

```bash
java StudentGradeTracker
```

### Step 3: Enter student details

Enter the number of students, their names, and their marks when prompted.

The program will display each student's marks along with the average, highest, and lowest marks.
